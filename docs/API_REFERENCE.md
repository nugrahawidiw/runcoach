# API reference

Generated by `scripts/gen_api_docs.py` from the source. Do not edit by hand; re-run the script.

### `runcoach/__init__.py`

runcoach: run-coaching analysis fed by the Strava API.


### `runcoach/analysis/readiness.py`

Readiness recommendation from the latest wellness night plus the planned session.

- `_sleep_hrv_gate(night: Night) -> tuple[bool | None, str]` *(private)* Shared condition: sleep score >= 60 and HRV status not Unbalanced.
- `evaluate(night: Night, kind: str, legs_flat: bool=False, profile: Profile | None=None) -> dict` Readiness for one planned session kind. Deterministic: same night and kind give the same result.
- `render_markdown(result: dict) -> str` Human-readable readiness note. Every line names the rule and its status.

### `runcoach/analysis/run_report.py`

Build a 'deep dive' for one run from Strava API data (activity + laps + streams).

- `_stream(streams: dict | None, key: str)` *(private)*
- `normalize_lap(lap: dict) -> dict` Accept Strava REST lap keys (average_heartrate ...) and the shorter names (avg_hr ...).
- `laps_from_splits(activity: dict) -> list[dict]` Fallback when an activity has no laps: Strava's 1 km metric splits.
- `_mean(values)` *(private)*
- `build_report(activity: dict, laps: list[dict], streams: dict | None, profile: Profile, kind: str='easy') -> dict`
- `render_markdown(rep: dict) -> str`

### `runcoach/config.py`

Athlete profile and environment handling.

- **class `Profile`**
- `load_profile(path: str | Path | None=None) -> Profile` Load profile.toml if present; otherwise use the defaults.

### `runcoach/fit/__init__.py`

Garmin FIT file support: wellness (sleep, HRV, stress ...) and activities (runs).


### `runcoach/fit/activity.py`

Turn a Garmin activity FIT file into the same structures the Strava path produces.

- **class `FitRun`**
- `_fill(values: list, max_gap: int=GAP_FILL_S) -> list` *(private)*
- `_smooth(values: list, half: int) -> list` *(private)*
- `grade_stream(altitude: list, distance: list, half: int=GRADE_HALF_WINDOW) -> list` Percent grade from smoothed altitude over +/- half seconds of travel.
- `activity_from_messages(msgs: list[Message]) -> FitRun`
- `cache_id(run: FitRun) -> str` Stable cache key from the start time, e.g. fit-20261011072225.

### `runcoach/fit/reader.py`

Read FIT files, zips of FIT files, or folders, into plain Message objects.

- **class `Message`**
  - `get(self, key, default=None)`
- `fit_time(value) -> dt.datetime | None` FIT timestamps arrive as datetimes (known fields) or epoch seconds (unknown fields).
- `fit_seconds(value: dt.datetime) -> int`
- `iter_fit_bytes(data: bytes, name: str='') -> Iterator[Message]`
- `iter_path(path: str | Path) -> Iterator[Message]` Messages from one .fit, one .zip of .fit files, or a folder of either (recursive).
- `iter_groups(path: str | Path) -> Iterator[tuple[str, list[Message]]]` Group messages per export. One zip = one group; a folder yields one group per zip.

### `runcoach/fit/wellness.py`

Garmin wellness: sleep, HRV, resting HR, stress, body battery from daily FIT exports.

- **class `Night`**
  - `to_dict(self) -> dict`
- `monitoring_samples(messages: Iterable[Message])` Yield (utc_datetime, heart_rate) for monitoring messages, expanding 16-bit timestamps.
- `local_offset(messages: Iterable[Message]) -> dt.timedelta` Device clock offset from monitoring_info (local_timestamp - timestamp).
- `stage_minutes(levels, start: dt.datetime, end: dt.datetime) -> dict` Minutes per sleep stage from sleep_level messages.
- `summarize_messages(messages: list[Message]) -> list[Night]` Summaries for every full night found in one export (usually exactly one).

### `runcoach/metrics/cadence.py`

Cadence handling. Strava run cadence is one foot (rpm); double it for steps/min.

- `to_spm(rpm_samples, min_rpm: float=60.0)` Steps/min per sample; None for sensor glitches (0, 41, 55, 57 ...).
- `mean_spm(rpm_samples, start: int, end: int, min_rpm: float=60.0) -> float | None` Mean steps/min over stream indices start..end inclusive, ignoring glitches.

### `runcoach/metrics/decoupling.py`

Aerobic decoupling and efficiency.

- **class `Decoupling`**
- `efficiency(distance_m: float, moving_s: float, avg_hr: float) -> float` Speed per heartbeat x1000 (m/s per bpm x 1000). Higher is better.
- `_after_skip(laps, skip_m)` *(private)*
- `decoupling(laps, skip_first_m: float=1000.0, use_gap: bool=False) -> Decoupling | None` Half-split decoupling (efficiency factor = speed / HR), first km excluded.

### `runcoach/metrics/gap.py`

Grade-adjusted pace using the Minetti et al. (2002) running-cost polynomial.

- `minetti_cost(grade: float) -> float` Metabolic cost (J/kg/m) at a gradient given as a fraction (+0.05 = +5%).
- `gap_factor(grade_pct: float) -> float` Cost relative to flat ground. >1 uphill, <1 gentle downhill.
- `gap_pace(pace_s_per_km: float, grade_pct: float) -> float` Flat-equivalent pace (s/km) for the effort at this grade.

### `runcoach/metrics/load.py`

Training load: TRIMP and the CTL / ATL / TSB model.

- `banister_trimp(hr_samples, time_samples, hr_rest: float, hr_max: float, sex: str='male') -> float` Banister TRIMP from an HR stream. Scale differs from Strava Relative Effort.
- `step(ctl: float, atl: float, load: float, ctl_days: int=42, atl_days: int=7)` Advance one day. Exponential weighting: alpha = 1 - exp(-1/N).
- **class `LoadPoint`**
  - `tsb(self) -> float`
- `load_series(daily_loads: dict[date, float], start: date, end: date, ctl0: float=0.0, atl0: float=0.0)` Daily CTL/ATL/TSB from start to end inclusive (days without data = rest).

### `runcoach/metrics/pace.py`

Pace and time helpers. Pace is seconds per km everywhere in this package.

- `pace_from_speed(speed_mps: float | None, min_speed: float=0.8) -> float | None` Seconds per km from m/s; None for stops or missing data.
- `fmt_pace(sec_per_km: float | None) -> str`
- `fmt_time(seconds: float) -> str`
- `parse_time(text: str) -> float` '2:08:21' or '26:17' -> seconds.

### `runcoach/metrics/vdot.py`

Daniels/Gilbert VDOT and Riegel race-time projection (approximate by design).

- `vdot(time_s: float, dist_m: float) -> float`
- `time_for_vdot(v: float, dist_m: float) -> float` Equivalent race time (s) at a distance for a VDOT (bisection).
- `riegel(time_s: float, from_m: float, to_m: float, exponent: float=1.06) -> float`

### `runcoach/metrics/zones.py`

Heart-rate time-in-zone and the easy-HR guide check.

- `zone_for(hr: float, lowers: Sequence[int]) -> str` Zone name for one heart-rate sample, given the four lower bounds of Z2..Z5.
- `time_in_zone(hr_data: Iterable[float | None], lowers: Sequence[int]) -> dict[str, int]` Seconds per zone from a 1 Hz heart-rate stream. Missing samples are skipped.
- `easy_guide_split(hr_data: Iterable[float | None], guide: int) -> tuple[int, int]` Seconds at or below the easy-HR guide, and seconds above it. The guide is inclusive.

### `runcoach/strava/auth.py`

Strava OAuth2: authorize once in a browser, then refresh tokens automatically.

- **class `Tokens`**
  - `expired(self, now: float | None=None, margin: float=60.0) -> bool`
- **class `TokenStore`** Tokens live in one JSON file with owner-only permissions.
  - `load(self) -> Tokens | None`
  - `save(self, tokens: Tokens) -> None`
- `authorize_url(client_id: str, redirect_uri: str, scope: str=DEFAULT_SCOPE) -> str`
- `_token_request(payload: dict, session) -> Tokens` *(private)*
- `exchange_code(client_id: str, client_secret: str, code: str, session=None) -> Tokens`
- `refresh_tokens(client_id: str, client_secret: str, refresh_token: str, session=None) -> Tokens` Strava issues a NEW refresh token on every refresh; always store the result.
- `run_local_flow(client_id: str, client_secret: str, redirect_uri: str, store: TokenStore, scope: str=DEFAULT_SCOPE, open_browser: bool=True, session=None) -> Tokens` Open the consent page, catch the redirect on localhost, exchange the code, save tokens.

### `runcoach/strava/cache.py`

Tiny JSON file cache so each activity is fetched once (API calls are rationed).

- **class `Cache`**
  - `has(self, kind: str, key) -> bool`
  - `get(self, kind: str, key)`
  - `put(self, kind: str, key, obj) -> None`
  - `ids(self, kind: str) -> list[str]`

### `runcoach/strava/client.py`

Thin Strava API v3 client: automatic token refresh, 429 handling, rate-limit logging.

- **class `StravaClient`**
  - `list_activities(self, after: int | None=None, before: int | None=None, per_page: int=100, max_pages: int=10) -> list[dict]`
  - `get_activity(self, activity_id: int | str) -> dict | None`
  - `get_laps(self, activity_id: int | str) -> list[dict]`
  - `get_streams(self, activity_id: int | str, keys=STREAM_KEYS) -> dict` Full-resolution streams keyed by type: {'time': {'data': [...]}, ...}.
  - `get_gear(self, gear_id: str) -> dict | None`

### `runcoach/strava/errors.py`

- **class `StravaError`** Any Strava API problem.
- **class `AuthError`** Missing, expired or rejected credentials. Run `runcoach auth`.
- **class `RateLimitError`** HTTP 429. Strava limits are per 15 minutes and per day; wait and resume.

### `runcoach/strava/sync.py`

Pull recent runs into the local cache (3 API calls per new run).

- **class `SyncResult`**
- `sync_recent(client: StravaClient, cache: Cache, days: int=14, force: bool=False, now: float | None=None) -> SyncResult`
